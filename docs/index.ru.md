# Привет из википедии по Unminal Engine

---

### **Unminal Engine - свобода воли, свобода действий*
* Движок **не указывает свои правила**; он лишь дает вам инструменты **что-бы воспроизвести ваше видинее** в жизни.
* Помогите сохранить этот дух живым: **поставите звезду репозиторию** и **и смотрите как Unminal развивается!**
* Простой, с открытым исходным кодом 3Д игровой движок созданный с нуля на C# используя OpenTK.

## История проекта

В начале, Unminal расчитывалась как игра на подобии [*The Backrooms*](https://ru.wikipedia.org/wiki/закулисье) мультивселенной. Однако, увидев бесчисленное множество подобных проектов, автор спросил: __"Зачем создавать еще одну игру, когда можно создать инструмент для тысяч других?"__

И теперь __Unminal Engine__ (ранее EOCS) это инди-движок, созданный из чистого любопытства и превратившийся в полноценную платформу для творчества.
