## About Project

### Features
1. Import objects with textures (UV mapping)
2. Update Graphics
3. Implement AABB collision (at beginning only with built-in shapes)
4. Create water surfaces (visually, without collision)
5. Particles

## History of project

Originally, Unminal was conceived as a horror game set in [*The Backrooms*](https://en.wikipedia.org/wiki/The_Backrooms) universe. However, upon seeing countless similar projects, the author asked: __"Why make yet another game when you can build a tool for thousands of others?"__

And so __Unminal Engine__ (formerly EOCS) was born — an indie engine crafted out of pure curiosity, evolving into a full-fledged platform for creativity.
